# skema-buehnenprobe

Probe-App (Spike S1-H) fuer das Hallen-iPad des SLSHM: Prueft, ob eine eigene iPad-App per HDMI
von selbst ein randloses Bild auf dem Fernseher zeigt und die Buehne der Web-App live mitzeichnet.

Kein Produktcode. Die App selbst liegt in einem privaten Repo; hier stehen nur die Probe (Swift,
XcodeGen) und ihr Bau-Ablauf auf einem macOS-Runner von GitHub.

Bauzettel und Ergebnis: im privaten Repo unter `docs/plan/45-bauzettel-probe-s1h.md`.
